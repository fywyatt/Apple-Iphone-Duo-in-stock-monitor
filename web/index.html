    Set up Stock Monitor

    Choose a working folder

    This is where the monitor keeps its history and email settings. The default folder is ready to use.

    To make a new folder, add its name to the end of the path. To reopen old history, choose the folder where it was saved.

    Monitoring lists

    Each list has its own ZIP codes and alert recipients. Products can use those recipients or have their own.

    The default is 60 seconds between checks for each ZIP code.

    Enter 0–59. For example, 20 starts at the next :20. Later checks follow your interval. Leave blank to start immediately.

    Get an email when stock appears

    Set up the sender used by all monitoring lists. Stock checks can run with email alerts disabled. Each recipient gets five emails per product restock alert.

    For Gmail, use an app password from the sender’s Google Account. Port 587 uses STARTTLS and port 465 uses implicit TLS.
